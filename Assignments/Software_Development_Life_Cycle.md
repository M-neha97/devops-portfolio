# Software Development Life Cycle (SDLC)

## 📌 What is SDLC?

Software Development Life Cycle (SDLC) is a structured and systematic
process used by development teams to design, develop, test, and deliver
high-quality software applications that meet client requirements.

------------------------------------------------------------------------

# 🔄 SDLC Phases Overview

The SDLC consists of the following phases:

1.  Requirement Gathering\
2.  Planning\
3.  Designing\
4.  Development\
5.  Testing\
6.  Deployment\
7.  Release / Live

------------------------------------------------------------------------

# 📌 Detailed SDLC Flow

### 1️⃣ Requirement Gathering

-   Understand client requirements
-   Define application type
-   Identify features

### 2️⃣ Planning

-   Cost estimation
-   Timeline definition
-   Team allocation

### 3️⃣ Designing

-   Infrastructure decisions
-   Database selection
-   API & UI/UX design

### 4️⃣ Development

-   Developers write application code

### 5️⃣ Testing

-   Manual & Automation testing
-   Bug fixing

### 6️⃣ Deployment

-   Deploy to Dev, Test, Production
-   Sanity testing

### 7️⃣ Release / Live

-   Deploy to production server
-   Handover to client

------------------------------------------------------------------------

# 🚀 Agile Model (Sprint-Based Development)


Agile divides the project into smaller iterations called **Sprints**.

Example: - Sprint 1 → Add school info - Sprint 2 → Edit school info -
Sprint 3 → Update school info - Sprint 4 → Delete school info

Each Sprint goes through all SDLC phases.

------------------------------------------------------------------------

# 🌊 Waterfall Model

Waterfall is a linear approach where:

-   All requirements are gathered upfront
-   Each phase is completed before moving to the next
-   Changes later are difficult

Flow: Requirement → Planning → Designing → Development → Testing →
Deployment → Release

------------------------------------------------------------------------

# ⚖️ Agile vs Waterfall

  Feature               Agile         Waterfall
  --------------------- ------------- -----------
  Flexibility           High          Low
  Requirement Changes   Allowed       Difficult
  Delivery              Incremental   Final
  Speed                 Faster        Slower

------------------------------------------------------------------------

# 🎯 SDLC from DevOps Perspective

As a DevOps Engineer, responsibilities include:

-   CI/CD pipeline implementation
-   Infrastructure automation
-   Deployment automation
-   Monitoring & Logging
-   Production support

DevOps enhances SDLC by improving speed, reliability, and automation.

------------------------------------------------------------------------

# ✅ Conclusion

SDLC provides a structured way to build quality software.\
Modern development commonly uses **Agile + DevOps** for faster and
continuous delivery.
